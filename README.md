# Cosmic Samba Manager

Нативное приложение для рабочего стола **Cosmic** (Pop!_OS) на Rust + libcosmic.

Безопасно управляет Samba-сервером и шарами, сохраняя существующую конфигурацию.

## Возможности

- Старт / стоп / статус `smbd`
- Добавление и удаление шар с валидацией
- Права доступа (Read only / Guest, guest по умолчанию выключен)
- Комментарии
- Управление пользователями Samba
- Выбор папки (zenity / ручной ввод)
- **Безопасная запись smb.conf**: привилегированный helper, резервная копия, обязательный `testparm`, атомарная замена
- Сохранение исходных строк, комментариев, глобальных параметров и неизвестных настроек
- Удаление шары из интерфейса действительно удаляет её секцию при сохранении

## Требования

- Pop!_OS / Cosmic (Wayland)
- Rust stable
- Samba (`smbd`, `smbpasswd`, `pdbedit`, `testparm`)
- `zenity` (опционально, для выбора папки)
- `just` (опционально)

## Сборка и установка

```bash
git clone https://github.com/krmobdev/cosmic-samba
cd cosmic-samba
just build-release
just install
```

## Привилегии

Операции, требующие административных прав:
- Запуск/остановка/`reload` `smbd` (`systemctl`)
- Запись в `/etc/samba/smb.conf`
- Создание системных пользователей (`useradd`)
- Управление пользователями Samba (`smbpasswd`)

Приложение запускается от обычного пользователя. Для записи `/etc/samba/smb.conf` и управления пользователями используется отдельный внутренний режим приложения через `pkexec`. Пароли не передаются в аргументах команд и не записываются в логи.

## Безопасность конфигурации

При сохранении:
1. Приложение читает исходный файл и отказывается продолжать при ошибке чтения или неоднозначной конфигурации.
2. Изменяются только параметры `path`, `comment`, `read only` и `guest ok` в файловых шарах, управляемых через интерфейс.
3. Остальные строки, комментарии, глобальные параметры, неизвестные параметры и специальные секции без `path` сохраняются.
4. Конфигурация проверяется обязательным `testparm`; если утилита отсутствует или проверка не проходит, запись отменяется.
5. Создаётся резервная копия `smb.conf.bak`, затем файл заменяется атомарно с сохранением прав и владельца.

Конфигурации с `include` или `config file` пока намеренно не редактируются: приложение сообщает об этом и просит сначала объединить включаемые файлы вручную. Символическая ссылка вместо `smb.conf` также отклоняется.

## Устранение неисправностей

- Если конфиг не сохраняется — проверьте права и вывод `testparm -s /etc/samba/smb.conf`
- Резервная копия: `/etc/samba/smb.conf.bak`
- Логи: `journalctl -u smbd`
