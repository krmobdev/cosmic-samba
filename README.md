# Cosmic Samba Manager

Нативное приложение для рабочего стола Cosmic (System76) на Rust.

Управляет Samba-сервером и позволяет добавлять собственные шары (shares).

## Возможности (в разработке)

- Старт / стоп / статус smbd
- Добавление и настройка шар
- Интеграция с Cosmic (libcosmic + iced)

## Сборка

```bash
cargo build --release
```

Требуется установленный Samba (`smbd`, `systemctl`).
