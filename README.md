# Cosmic Samba Manager

Нативное приложение для рабочего стола **Cosmic** (Pop!_OS) на Rust + libcosmic.

Безопасно управляет Samba-сервером и шарами, сохраняя существующую конфигурацию.

## Возможности

- Старт / стоп / статус `smbd`
- Добавление и удаление шар с валидацией
- Права доступа (Read only / Guest, guest по умолчанию выключен)
- Комментарии
- Управление пользователями Samba
- Выбор папки (zenity / ручной ввод)
- **Безопасная запись smb.conf**: резервная копия, `testparm`, атомарная замена, откат
- Сохранение существующих глобальных параметров и неизвестных настроек шар

## Требования

- Pop!_OS / Cosmic (Wayland)
- Rust stable
- Samba (`smbd`, `smbpasswd`, `pdbedit`, `testparm`)
- `zenity` (опционально, для выбора папки)
- `just` (опционально)

## Сборка и установка

```bash
git clone https://github.com/krmobdev/cosmic-samba
cd cosmic-samba
just build-release
just install
```

## Привилегии

Операции, требующие административных прав:
- Запуск/остановка/`reload` `smbd` (`systemctl`)
- Запись в `/etc/samba/smb.conf`
- Создание системных пользователей (`useradd`)
- Управление пользователями Samba (`smbpasswd`)

Приложение использует `pkexec` при необходимости. Запускайте от обычного пользователя — политика polkit запросит пароль.

## Безопасность конфигурации

При сохранении:
1. Создаётся резервная копия `smb.conf.bak`
2. Конфиг проверяется `testparm`
3. При успехе — атомарная замена
4. При ошибке исходный файл остаётся нетронутым (откат из бэкапа)

Существующие глобальные параметры и неизвестные настройки шар сохраняются.

## Устранение неисправностей

- Если конфиг не сохраняется — проверьте права и вывод `testparm -s /etc/samba/smb.conf`
- Резервная копия: `/etc/samba/smb.conf.bak`
- Логи: `journalctl -u smbd`
